# Rebuild Profit Estimator

Streamlit app for Seoul / capital-area apartment rebuild deal analysis.

## Run

```bash
pip install -r requirements.txt
streamlit run rebuild_estimator_app.py
```

## Scope

- Apartment rebuild only
- Three scenarios: `Optimistic`, `Base`, `Conservative`
- Outputs: legacy asset estimate, rights value, allocation candidates, project feasibility, personal PnL
- Document inputs: `PDF`, `CSV`
